Line-Up Packet

Print tomorrow's line-up sheets

One sheet per team member for the green bin. The front is the line-up sheet: the menu by station, the timeline, event notes, a place to write your assignment and a QR code to the station set-up guides. The back shows photos of the dishes. It takes about a minute.

  1. 1
    Save the SEOsIn Caterease, save each of tomorrow's Production SEOs as a PDF. Put them in one folder so they are easy to find.
  2. 2
    Drop them all inOpen the Line-Up Packet page and drag every SEO onto it at once, or click the box and pick them. The files stay on your computer.
  3. 3
    Set copies and press PrintType the number of copies for each event, one per team member. Print double-sided. The sheets come out in order of event time, ready for each green bin.

If something shows up in yellow or red

Nothing to checkThe packet is ready. This is what you will see most days.
A yellow note on a packetRead it before printing. It tells you when a date has passed, a guest count is missing, or two files have the same SEO number.
A red box with a file nameThat file was not an SEO or could not be read, so it was skipped. Save the SEO from Caterease again and add it with Add more SEOs.
The print window does not openUse the "open the packets" link under the Print button and print from there.

Changing a packet

You should not need to. If a supervisor asks for a change, press Make changes on that event. You can type in the supervisor and lead chef, leave a station out, join two stations or turn a photo off. Press Done when you are finished.
